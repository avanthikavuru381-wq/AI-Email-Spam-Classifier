# AI-Powered Email Spam Classifier

## Module 6 - Final AI & ML Project

This project is developed as part of **Module 6 - Final AI & ML Project** for the Codomax Digital Solutions internship.

The project uses Machine Learning and Natural Language Processing techniques to classify an email or text message as **Spam** or **Not Spam**.

---

## Project Objective

The main objective of this project is to build a simple AI/ML application that can automatically identify unwanted or spam messages.

The project demonstrates how Machine Learning can be applied to a real-world text classification problem.

---

## Features

- Classifies messages as Spam or Not Spam
- Uses TF-IDF for text feature extraction
- Uses Logistic Regression for classification
- Displays prediction confidence
- Shows model accuracy
- Provides an interactive Streamlit interface
- Uses a labeled dataset for model training
